# Hookah Split — Telegram Web App (S0)

Мини-приложение для учёта «чаш» (кальянов) и честного дележа расходов.  
**Этап S0:** без бэкенда, все данные локально у пользователя, экспорт/импорт JSON.

> Репозиторий монорепо: этот проект живёт в подпапке `hookah-split-twa/`.  
> Корень репозитория: `HookahCalc/`.

## ✨ Возможности (S0)
- Сессия: название, место, **цена за чашу в целых рублях**.
- Участники, «+ Чаша», автоматический раздел.
- Итоги: личные балансы и **минимальные переводы**.
- Экспорт/импорт состояния (JSON), шеринг текста итогов.

## 🧱 Технологии
- React + TypeScript + Vite
- Локальное хранилище: `localStorage` (опционально IndexedDB на будущее)
- Без серверной части на S0

## 🚀 Локальный запуск

Выполняй команды из папки проекта:

```bash
cd hookah-split-twa
