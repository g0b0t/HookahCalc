# Hookah Split — Telegram Web App (S0)

Мини-приложение для дружеского учёта «чаш» (кальянов) и честного дележа расходов.  
**Этап S0:** без бэкенда, все данные локально у пользователя (браузер), экспорт/импорт JSON.

## ✨ Возможности (S0)
- Создать сессию (название, место, **цена за чашу в рублях**).
- Добавлять участников и отмечать, кто участвует в текущей чаше.
- «+ Чаша» — добавляет запись, цена делится поровну; остаток распределяется детерминированно.
- Итоги: личные балансы и список **минимальных переводов** (взаимозачёт).
- Экспорт/импорт состояния в JSON.
- Шеринг итогов (через Web Share API или копирование текста).

> На S0 нет совместной работы: это «личный» учёт на одном устройстве. На S1/S4 подключим бэкенд.

## 🧱 Технологии
- React + TypeScript + Vite
- Локальное хранилище: `localStorage` (опционально — IndexedDB)
- Никаких серверов / баз данных на S0
