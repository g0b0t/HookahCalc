# HookahCalc

Мини-экосистема для учёта «чаш» (кальянов) и честного дележа расходов между друзьями.  
Стартуем с **Telegram Web App (TWA)** без бэкенда, храним данные локально. Постепенно эволюционируем к полноценному бэкенду на **Java + Postgres** и интеграции **NFC**.

> Текущий статус: **S1 (бекенд без авторизации и хранение не в БД)** — рабочее TWA-приложение в подпапке `hookah-split-twa/`.

## Дорожная карта

**S0 — Solo TWA, без бэкенда (готово)**  
- Хранение локально (`localStorage`)
- Сессии, участники, «+ чаша», итоги и взаимозачёт
- Экспорт/импорт JSON
- Цены в **целых рублях**

**S1 — Мини-бэк на Java (файлы вместо БД)**  
- Тот же REST-контракт, что в финальной версии  
- Хранилище: JSON-файлы на сервере  
- Валидация `initData` Telegram на бэке  
- Deeplink/QR/NFC-ready поток

**S2 — Надёжность/наблюдаемость**  
- Логи JSON, rate-limit, метрики (Actuator/Micrometer), бэкапы

**S3 — NFC и UX улучшения**  
- Поток через `startapp`, QR, запись URL на NDEF-метку

**S4 — Финальный бэк на Java + Postgres**  
- Spring Boot + JPA + Flyway  
- Импорт данных из S1  
- Те же API — фронт не меняем
